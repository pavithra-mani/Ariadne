# External sources register

Every external thing Ariadne relies on (data, models, documents, benchmarks, price feeds) is recorded here so a paper can cite it
and a reader can check it. Rules: add a row **when you first use** a source; record the retrieval date, licence/terms as stated
(or "not stated"), what it is used for, and where in the repo. Never paste secrets. Third-party files are not committed unless
the licence allows; the register says where they live locally.

* `SOURCES.md` - the register (human readable)
* `../data/kb/SOURCES.md` - detail for the 13 knowledge-base documents (listed here by reference)
